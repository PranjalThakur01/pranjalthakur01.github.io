# Pranjal Thakur - Software Engineer Portfolio

A highly interactive, scalable, and performance-optimized 3D portfolio built entirely from scratch without relying on heavy 3D frameworks like Three.js or WebGL libraries.

🌐 **Live Demo:** [pranjalthakur01.github.io](https://pranjalthakur01.github.io/)

## 🚀 Technical Highlights

* **Pure Vanilla Architecture:** Built utilizing strictly Vanilla HTML5, CSS3, and ES6 JavaScript, demonstrating a deep understanding of core web technologies and DOM manipulation.
* **Complex Canvas Animation:** Features a 290-frame high-resolution image sequence synced to scroll events using HTML5 `<canvas>`, providing a smooth, Apple-like 3D scrolling experience with minimal performance overhead.
* **Custom CSS Orbit Engine:** Engineered a continuous, seamless, and imaginary 3D tech-stack orbit animation using advanced CSS keyframes, complex transform functions (rotate, translate), and dynamic CSS variables (`--angle`) to maintain horizontal text alignment during orbital rotation.
* **Glassmorphism & Responsive UI:** Implemented a modern, responsive design system utilizing CSS Grid, Flexbox, and backdrop-filters to achieve a premium UI across all viewport sizes.
* **Formspree Integration:** Configured an asynchronous contact form pipeline utilizing Formspree for serverless email routing.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Animation:** HTML Canvas API, CSS3 Keyframes & Transitions
* **Version Control & Hosting:** Git, GitHub Pages
* **Integrations:** Formspree API
